# HCL — Smart Sleep Companion

基于三张参考图实现的移动端交互原型，使用 React 19、TypeScript、Vite 6、Tailwind CSS 4 和 Lucide 图标。界面保留参考图的英文文案。

## 启动

```sh
npm install
npm run dev -- --port 5173
```

本地地址：<http://localhost:5173>。生产构建：`npm run build`；预览构建：`npm run preview`。

## 单个 HTML 文件分享

运行 `npm run build:single`，在项目根目录生成 `Smart-Sleep-Companion.html`（约 281 KB）。只需将这个文件发给试用者，无需附带其他文件。

下载后用 Chrome、Edge 等现代浏览器打开；聊天工具的附件预览不一定执行网页脚本。页面的脚本、样式、图标和提示音均无需联网。提醒声音需要先点击页面以启用；自动提醒仍需保持网页打开。设置保存在试用者自己的浏览器中，不会上传。

已在 Chromium 中通过 `file://` 直接打开并启用离线模式验证：六页交互、三种主题、设置刷新保持、自动提醒、模拟提醒及提示音均通过，无外部网络请求和浏览器控制台错误。

## 使用路径

1. 首次访问进入 **Sleep Plan Setup**，修改时间及准备时长，点击 **Create My Plan** 进入 Home。
2. 底部导航访问 Home、Wind-Down、Insights、Me；Home 的睡眠目标卡片可重新修改计划。
3. Wind-Down 支持三个开关、提醒提前量和应用选择；应用选择弹窗点 **Done** 后，点击页面的 **Save Changes** 应用设置。
4. **Start Wind-Down** 在 Home 展示按准备时长计算的倒计时，以及静音、灰度和锁定应用的模拟状态。**End Wind-Down** 可提前结束。
5. 开启 Bedtime Reminder 后，网页会按设备本地时间在目标睡眠时间自动弹窗，播放轻柔的三音提示。Home 右上角铃铛或 Me 的 **Test Bedtime Reminder** 也可打开测试入口。设置模拟时间和 Phone in use，点击 **Check Reminder**。默认时间是睡眠目标之后 7 分钟，模拟提醒也播放提示音。
6. 提醒页面支持开始准备、延迟 10 分钟和跳过。延迟后，在测试入口点击 **Advance 10 min** 可再次触发；**Reset Simulated Night** 清除延迟、跳过及运行状态。
7. Me → **Appearance** 是唯一主题选择入口。Light、Dark、High Contrast 立即全局生效并自动保存；个人偏好使用 **Save Preferences** 保存。

## 主题与数据

- `ThemeContext.tsx` 管理全局主题；`styles.css` 使用 CSS Variables 驱动所有页面、导航、图表、控件及弹窗。
- 默认 Light：暖白、浅桃、陶土橙；Dark：深棕、暖橙和柔和浅色；High Contrast：纯黑白、黄色强调、黑色明显边框。
- `sleep-settings` 和 `sleep-theme` 使用 LocalStorage 保存。无有效历史设置时使用默认值；解析无效存储时回退到默认设置。
- 手机使用量固定模拟为 48 分钟。目标完成度为 `min(100, floor(目标分钟 / 48 × 100))`，默认显示 62%。
- Week / Month / All Time 对应 7 / 28 / 84 个夜晚；折线分别展示每天、每 7 天平均、每 14 天平均入睡时间。
- 一致性为 `max(0, round(100 − 平均目标时间偏差分钟 / 1.6))`；手机使用统计为对应期间的夜均值。默认周数据为 86% 和 36 分钟。
- 时间以中午为睡眠夜的分界，正确处理 23:00 目标与 00:10 提醒的跨午夜情况。
- 提醒条件：开启提醒、手机在使用、到达提前提醒时间、尚未到起床时间、未跳过且延迟已到期。
- 模拟提醒的延迟、跳过和进行中的准备属于当前模拟会话状态；刷新会重置这些状态。真实时间提醒的已提醒记录、延迟截止时间和今晚跳过状态单独保存到 `sleep-live-reminder`，刷新保持，并在下一个睡眠夜重新开始。计划、个人偏好及主题保持。
- 不连接系统通知、真实应用锁定、屏幕灰度或硬件。灰度仅作用于模拟预览，不会覆盖用户所选主题。

## 自动提醒与提示音

- 保存睡眠计划后，开启 Bedtime Reminder 即启用真实时间自动提醒。每秒检查一次，到目标睡眠时间在当前页面上方弹窗；正在 Wind-Down 时不打断。
- 自动弹窗按目标睡眠时间触发；测试入口继续按模拟时间和 Reminder Time 的提前量检查。模拟测试的手机状态、延迟和跳过不会修改真实提醒的记录。
- 弹窗提供 Start Wind-Down、Snooze 10 min、Skip Tonight；关闭弹窗也视为今晚跳过。正常提醒每个睡眠夜只显示一次，延迟到期可以再次显示。
- 页面需保持打开。回到页面时会补查：若已到睡眠时间且尚未到起床时间，显示未处理的提醒。关闭网页、浏览器冻结后台或系统锁屏时无法保证准时提醒。
- 提示音通过 Web Audio API 合成，无外部音频下载。点击或键盘操作会尝试启用音频；若浏览器限制自动播放，弹窗仍正常显示，并提供 **Enable & Play Reminder Sound** 按钮。设备音量与静音状态仍由设备控制。
- `useBedtimeReminder.ts` 管理真实时间调度、跨午夜和持久化；`reminderSound.ts` 负责音频启用、播放与停止。
